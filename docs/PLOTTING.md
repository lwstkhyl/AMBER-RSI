# RLDpred-BE: plotting

[English README](../README.md) | [中文README](../README.zh-CN.md)

The main and supplementary figures are generated from result tables. No training is performed by the standalone plotting scripts. Panel labels are uppercase A–D, and figure exports are PDF only.

## Scripts and configuration

| Script | Fonts | Size policy |
|---|---|---|
| `plotting/plot_figures.py` | Matplotlib's bundled DejaVu Sans | Original layout sizes; no 12pt minimum |
| `plotting/plot_figures2.py` | Real Helvetica regular and bold files | At least 12pt for ordinary text and mathematical subscripts at original PDF size |

The DejaVu Sans script ignores `figures.font_family`, `min_font_size` and `font_dir`. Selecting Helvetica in a configuration does not switch this script into the Helvetica version. The unified `run.sh plot` and `all` stages always call `plotting/plot_figures.py`.

Run commands below from the repository root in the installed environment. `--work` selects existing input tables; `--out` selects a separate output root. Omitting `--out` writes into the input run directory.

## DejaVu Sans

```bash
python plotting/plot_figures.py \
  --config config.example.json \
  --work /absolute/path/output/run01 \
  --out /absolute/path/output/figures_dejavu
```

For the supplied default architecture and canvas, the template is sufficient for standalone plotting; its Slurm and data-path placeholders are not used. If the bottleneck or canvas settings were changed, use that run's actual configuration instead. The `training.bottleneck` value is used in the model diagram.

## Helvetica

Place licensed regular and bold `.ttf`, `.otf` or `.ttc` font files in `fonts/Helvetica/`. Their internal family must resolve to `Helvetica`; renaming another font file does not change its family. The script loads these files directly without a system-wide font installation and rejects missing families or required symbols.

Create an independent plotting configuration:

```bash
python - <<'PY'
import json
from pathlib import Path

config = json.loads(Path("config.example.json").read_text(encoding="utf-8"))
config["figures"].update(
    model_name="RLDpred-BE",
    font_family="Helvetica",
    min_font_size=12,
    font_dir="fonts/Helvetica",
)
Path("config.plot.local.json").write_text(
    json.dumps(config, ensure_ascii=False, indent=2) + "\n",
    encoding="utf-8",
)
PY

python plotting/plot_figures2.py \
  --config config.plot.local.json \
  --work /absolute/path/output/run01 \
  --out /absolute/path/output/figures_helvetica
```

If customized settings must be retained, replace the template input above with `config.json` or the existing run's `config.snapshot.json`. A relative `font_dir` is resolved against the directory containing the plotting configuration; an absolute path is also accepted.

For a completed run with its snapshot and all required tables, the helper creates this configuration automatically and runs the Helvetica script:

```bash
bash plotting/replot_helvetica.sh \
  /absolute/path/output/run01 \
  /absolute/path/output/RLDpred_BE_figures_helvetica \
  /absolute/path/to/Helvetica_fonts
```

The helper preserves the run's model/canvas parameters and explicitly sets `model_name="RLDpred-BE"`, including when the old snapshot contains the previous name. The output directory must be outside the input run. The helper requires that run's `config.snapshot.json`; use the manual configuration above for tables without a snapshot. Project-specific server commands are in the [Chinese replotting guide](REPLOT_HELVETICA.zh-CN.md).

`config.plot.local.json` is created by the command above. `config.snapshot.json` is generated by the full pipeline inside a run directory, not by standalone plotting. Neither is required for the DejaVu Sans template example.

## Required tables

| Figure | Tables beneath `--work` |
|---|---|
| Main | `summary/total_results.tsv`, `summary/position_predictions.tsv`, `summary/target_metrics.tsv` |
| Supplementary | `plot_data/distance_per_target.tsv`, `plot_data/observed_window_summary.tsv`, `transfer/summary/condition_metrics.tsv`, `transfer/summary/editing_window_curve.tsv`, `transfer/summary/metrics_by_length.tsv` |

Use tables from one analysis run. `run.sh plot` prepares the extra plotting inputs through `plotting/prepare_plot_data.py` and therefore also needs the original experiment archive. Standalone plotting requires the tables to exist already.

## Outputs and checks

The default invocation writes:

- `figures/Fig1_RLDpred-BE.pdf` and `figures/FigS1_RLDpred-BE.pdf` beneath `--out`;
- tabulated plot values under `plot_data/plotted_values/`;
- a source/version record at `provenance/plot_run_all.json`.

Use `--figure main` or `--figure supp` to generate one figure; the provenance record is then named `plot_run_main.json` or `plot_run_supp.json`. Use different output roots for the two font versions because their PDF filenames are identical. Inspect `layout_warnings` and visually check the PDFs. The Helvetica record additionally reports fonts and minimum glyph sizes.

The 12pt minimum applies to the original Helvetica PDF. Text scales with placement width: `final_size = original_size × final_width / original_width`. The default width is 16.8in (42.672cm); a 12pt label becomes approximately 5.06pt when placed at 18cm. A final-page 12pt requirement needs a layout designed for that final width.

Code/configuration fingerprints protect existing pipeline runs. After changing a plotting source file, regenerate figures with the standalone command and a new output root; resuming the changed source through an old pipeline run may be rejected.

Historical paths containing `LDpred_BE` and the internal `LDPRED_CONFIG` environment variable retain their existing spelling for compatibility. Archived audit records retain their original filenames and hashes. New figure labels, filenames and model manifests use RLDpred-BE; the plotted comparison table uses `rldpred_be_mse_pp2` for its model MSE column.
